🔌 Hệ Thống REST API Tích Hợp

Toàn bộ chức năng cắt xoay (PdfSimpli), tải ảnh web (Extension Downloader) và tạo ảnh AI đều có API REST độc lập, có thể gọi từ code Python, Node.js hoặc cURL.

POST /api/transform/rotate

Xoay hình ảnh theo góc chỉ định (degrees: 90, 180, 270 hoặc góc tự do). Hỗ trợ nhận ảnh dạng file upload hoặc base64 dataUrl. 

// Bấm "Chạy thử API xoay" để xem phản hồi JSON
POST /api/scrape-images

Quét trang web, trích xuất tất cả thẻ img, picture, srcset, css background và openGraph ảnh kèm định dạng và URL tuyệt đối. 

// Bấm "Chạy thử Quét ảnh" để xem danh sách ảnh tìm được
POST /api/ai/generate

Tạo ảnh nghệ thuật chất lượng cao từ Prompt văn bản (hỗ trợ tiếng Việt, phong cách anime, cyberpunk, 3d, v.v.). 

// Bấm "Chạy thử Tạo ảnh AI" để tạo ảnh trực tiếp qua API
